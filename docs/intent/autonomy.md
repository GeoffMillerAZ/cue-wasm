# Autonomy

## May
Inspect, design, implement and test scoped local changes; use bounded subagents;
update intent and reversible repo wiring. Preserve source drafts and unrelated edits.
Work on a named feature branch; use coherent conventional commits with a truthful
Verified line. No WIP on main. Current uplift is authorized by the owner.

## Ask
Publication/push, paid providers, credentials, sending private content externally,
production changes, destructive data removal or global configuration changes need
specific authority. Prepare the concrete reviewable result before asking.

## Never
Bypass approval/security controls; reset unrelated work; call fixture proof live
adoption; weaken failing assertions; silently rebaseline modified agent hooks/skills.

## Continuity
Update docs/tracking/implementation_tracker.md with outcome, commands, limitations
and next action. Save durable decisions in ADRs; keep the roadmap ordered. Fathom
thread notes supplement the tracker and do not replace runtime evidence.
